# Kampüs Etkinlikleri (Sprint 4 - React & Vite)
Vervel linki: https://sprint4-xi.vercel.app/

Bu proje, HTML ve Vanilla JavaScript ile yazılmış bir uygulamanın modern web teknolojileri (React, TypeScript ve Vite) kullanılarak yeniden yapılandırılmış halidir.

## 🚀 Teknolojiler
- **React (v18)** - Kullanıcı arayüzü
- **TypeScript** - Tip güvenliği ve veri modellemesi
- **Vite** - Hızlı geliştirme sunucusu ve build aracı
- **CSS** - Saf CSS ile responsive tasarım (Mobil öncelikli)
